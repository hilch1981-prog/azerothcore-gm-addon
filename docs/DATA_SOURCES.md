# 데이터 출처와 구성

이 저장소는 WoW 3.3.5a (12340) 애드온 소스와 생성된 Lua 검색 자료를 포함합니다. 설치 ZIP을 만드는 데 서버 접속이나 DB 수정이 필요하지 않습니다.

게임 버전 전용 데이터는 `GMminibar/Data/AC335/`, 검색용 생성 자료는 `GMminibar/Data/Generated/`에 있습니다. 각 폴더의 `SourceInfo.lua`와 `GMminibar/ThirdParty/`에 기준 기록이 있습니다.

현재 순간이동 목록은 `Data/Generated/Destinations.lua`를 사용합니다. 특정 지점의 캐릭터 착지는 `landing` 좌표를 우선합니다. 원본 NPC·만남의 돌 중심 좌표와 캐릭터 착지 좌표를 혼동하지 않습니다.

서버 명령은 해당 코어의 구현으로 확인하며, 다른 버전의 데이터를 교체해서 사용하지 않습니다. 생성에 사용한 전체 DB 덤프·클라이언트 지형·개인 서버 파일은 저장소에 배포하지 않습니다. 포함된 생성 Lua를 사용하면 현재 설치 ZIP을 다시 만들 수 있습니다.
