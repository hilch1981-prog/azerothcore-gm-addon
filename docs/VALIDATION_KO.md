# v1.0.0 검증 범위

확인일: 2026-09-14. 공개 배포 준비에서는 버전 표시·설치 문서·출처 경로를 정리했습니다. 기존 최신 설치판의 기능 코드와 게임 데이터는 유지했습니다.

3.3.5a / WOW Legends Repack 1.5.3에서 붉은십자군 수도원·검은심연 나락·울다만·마라우돈·아졸네룹·안카헤트·전쟁노래 협곡 양 진영 입구의 **탈것 출발 및 정상 착지 8건**을 확인했습니다. 아졸네룹과 안카헤트는 공용 만남의 돌 옆 동굴 바닥으로 이동합니다. ASP1.5 자체는 별도로 시험하지 않았습니다.

## 자동 검사

배포 소스의 Lua 문법, TOC 로드 경로와 대소문자, XML 참조, 버전 일치, 파일 무결성, 설치 ZIP 내용 일치를 검사합니다. Lua 5.1 모의 클라이언트에서 전체 로드와 내장 자체 검사를 실행합니다.

검사 결과는 저장소의 Actions에서 확인합니다. CI 성공은 실제 게임에서 모든 기능이 작동한다는 뜻이 아닙니다.

## 추가 게임 확인

- GM 메뉴·가방을 반복해서 열고 닫을 때 Lua 오류가 없는지 확인합니다.
- 아이템 사용과 가방 4칸 장착, 습득 표시와 주문 단계 갱신을 확인합니다.
- NPC·던전·공격대·전장으로 이동한 뒤 정상 바닥에 서는지 확인합니다.
- 다른 플레이어 및 파티원 적용은 서버의 권한·온라인·입장 조건을 함께 확인합니다.

모든 서버 빌드·아이템·주문·순간이동 지점에 대한 전수 게임 검증은 완료하지 않았습니다.
