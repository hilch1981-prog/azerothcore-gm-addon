# AzerothAdmin 3.4.0-335a 변경 내역

## 주요 크리처 브라우저

- 선별 목록을 56개에서 187개로 확장했다.
- 레이드, 던전, 월드 보스, 희귀·정예, 이벤트 보스, 훈련·기능 NPC, 주요 지도자를 분류한다.
- 결과를 이전/다음 페이지 대신 마우스 휠과 세로 스크롤바로 탐색한다.
- 사용자 게임 테스트에서 동작하지 않은 클라이언트 3D 미리보기와 좌우 회전 UI를 제거하고, 목록 영역을 넓혔다.
- 임의 외부 이미지를 포함하지 않으며, 일반 몹 전체 검색은 기존 koKR/Entry 검색으로 유지한다.

## 기능 퀵슬롯

- GM 명령 외에 검색, 창 열기, 토글 등 실행 가능한 `action` 버튼도 등록한다.
- 저장 키를 command/action 형식으로 구분하며 3.3.0 이하 SavedVariables의 원시 명령 키도 계속 읽는다.
- 퀵슬롯에서도 공통 실행 경로를 사용해 대상 검사, 인수 입력, 확인창 및 권한 검사를 보존한다.

## NPC 진단 명령

- `.npc info`, `.npc guid`, `.distance`에 실제 NPC 대상 필요 조건과 결과 확인 위치를 명확히 표시한다.
- 근처 검색은 서버 빌드별 기본 거리 차이를 피하기 위해 `.npc near 20`으로 실행한다.
- 서버 응답이 없을 때 단순 채팅 전송을 성공으로 표시하지 않고 `전송/응답 미확인`으로 구분한다.

## 확인 필요

- 크리처 창을 사용한 뒤 좌·우 마우스 버튼으로 캐릭터 이동과 시점 회전을 반복해 급회전·하늘 시야 회귀가 사라졌는지 확인한다.
- NPC 진단 명령은 실제 크리처를 선택하고 한 번에 하나씩 실행해 AzerothCore 시스템 채팅 응답과 RBAC 권한을 확인한다.
- 게임 내 검증 전에는 완료로 간주하지 않는다.
