# AzerothAdmin 3.3.0-335a 변경 내역

## 주요 크리처 브라우저

- 기존 통합 아이템 정보 창과 같은 900×610 다크/골드 프레임을 사용한다.
- 왼쪽 분류 스크롤, 상단 확장팩·소환 조건 필터, 한글/Entry 검색, 2열 결과 목록과 하단 실행 버튼으로 구성한다.
- 레이드 대표 보스, WotLK 던전 최종 보스, 월드 보스, 주요 NPC·진영 지도자 56개만 선별한다.
- 전체 크리처 데이터는 복제하지 않으며 기존 `KoKRSearchData.lua`의 전체 검색으로 전환할 수 있다.
- 즐겨찾기는 `AzerothAdminEasyDB.featuredCreatureFavorites`에 저장한다.

## 이동 및 소환

- `위치 이동`: `.go creature id Entry`
- `스폰 목록`: `.list creature Entry 20`
- `임시 소환`: `.npc add temp Entry`, DB 미저장
- `영구 생성`: `.npc add Entry`, DB 저장
- 임시·영구 소환 모두 확인창을 사용하며 영구 생성은 위험 작업으로 표시한다.

## 지역 제한 경고

- 레이드, 던전, 월드 보스는 원래 맵·인스턴스·조우·지역 스크립트에 의존할 수 있으므로 `지역 제한 가능`으로 표시한다.
- 해당 크리처를 다른 지역에 소환하면 AI 정지, 조우 미완료, 문/오브젝트 연동 실패 또는 서버 스크립트 오류가 발생할 수 있음을 툴팁과 확인창에 표시한다.
- 경고는 위험을 알리는 정적 분류이며 모든 커스텀 서버의 실제 스크립트 동작을 보증하지 않는다.

## 검증 범위

- 선별 Entry와 한글 이름이 내장 koKR 크리처 데이터와 일치하는지 자동 검사한다.
- 데이터 수량, 중복 Entry, 분류별 지역 제한 정책, TOC 로드 순서와 임시·영구 명령 분리를 자동 검사한다.
- 실제 게임 클라이언트 및 worldserver에서의 소환·AI 동작은 별도 게임 테스트가 필요하다.
