GM에드온[3.3.5a 아제로스코어] v3.0
WoW WotLK 3.3.5a / Interface 30300 / AzerothCore

설치
1. 기존 Interface\AddOns\AzerothAdmin 폴더를 백업 후 삭제합니다.
2. 압축 안의 AzerothAdmin 폴더 하나만 Interface\AddOns에 넣습니다.
3. 별도의 InvenCraftInfo / BlueItemInfo3 설치는 필요하지 않습니다.
4. 게임 접속 후 /aa 로 메인창을 엽니다.

주요 명령
/aa          메인 GM창
/aa tele     한글 순간이동
/aa fav      즐겨찾기 순간이동
/aa quest    퀘스트 도우미
/aa bank     은행 보기
/aa craft    전문기술 정보
/aa iteminfo 통합 아이템 정보/한글·ID 검색
/aa auth     GM 권한 재검사
/aa resetui  UI 위치 초기화

은행
- 은행 버튼은 Blizzard 기본 BankFrame만 중앙/이동 가능 형태로 열고 닫습니다.
- 별도 '은행 가방 · 원격 확인' 창은 더 이상 생성하지 않습니다. 원격 BankFrame 데이터 제공 여부는 서버 설정/코어 동작에 따릅니다.
- 원격 창은 드래그 이동/새로고침/페이지/ESC 닫기를 지원합니다.
- 같은 은행 버튼을 다시 누르면 현재 열린 은행 창이 닫힙니다.

전문기술 정보
- InvenCraftInfo 1.8.1을 AzerothAdmin 내부에 통합했습니다.
- 전문기술 전환 시 이전 전문기술의 선택/재료 정보를 즉시 초기화합니다.
- 재료는 이미지 없이 텍스트 한 줄 목록으로 표시합니다.
- 재료 좌클릭 -> 수량 입력 -> 현재 GM 캐릭터 가방에 .additem으로 추가합니다.
- 미습득 도안/기술은 주황색, 습득 완료는 초록색으로 표시합니다. 체크 표시는 사용하지 않습니다.
- 미습득 도안 또는 GM 습득 버튼 -> .player learn 캐릭터명 SpellID 방식으로 습득합니다.
- 도안에는 숙련/Lv./iLv. 정보를 가능한 범위에서 함께 표시합니다.

아이템 정보
- Blue Item Info 3의 분류/획득처 데이터를 한 창에 통합했습니다.
- 왼쪽에는 처음부터 '분류' 스크롤 목록을 표시합니다.
- 상단에서 종류(도안/주문, 무기, 방어구, 재료/보석, 소비품, 기타)와 등급을 체크한 뒤 '필터 적용'을 누릅니다.
- 필터 체크만으로 즉시 대량 재검색하지 않아 불필요한 반복 로딩을 줄였습니다.
- 대격변 공격대/5인 던전/세트/평판 및 관련 하위 분류는 UI에서 제외합니다.
- 분류 목록은 WotLK 3.3.5a 범위와 현재 WOW32 koKR 아이템 ID를 함께 검증합니다.
- 아이템 좌클릭 -> 수량 입력 -> 가방 추가. Shift 등 수정키 동작은 기본 아이템 링크 기능을 따릅니다.
- 아이템 등급색과 Lv./iLv.를 표시합니다.

퀘스트 도우미
- ID / 퀘스트명 / 레벨 / 지역 컬럼으로 표시합니다.
- 각 컬럼 제목 클릭 시 오름차순/내림차순 정렬됩니다.
- 퀘스트 한글/ID 검색, 등록, 완료, 시작/종료 위치, 목표 기능을 제공합니다.

ESC / 창 순서
- 메인 -> 세부창 -> 입력/확인 팝업 순으로 열었으면 ESC도 가장 마지막 팝업부터 한 단계씩 닫힙니다.
- 자식 창을 닫으면 직전 부모창이 복원됩니다.
- 팝업을 닫는 한 번의 ESC가 부모창까지 같이 닫지 않도록 Escape Proxy를 일시 중지합니다.

GM 명령
- 사용자 제공 acore_world.command 약 740개 기준으로 애드온 명령을 대조한 CommandMeta를 사용합니다.
- 버튼 툴팁에 Syntax/필요 GM 레벨을 표시하고 실행 결과 및 권한/RBAC 상태를 표시합니다.
