# AzerothAdmin 모듈 계약

이 폴더는 기능별 코드의 최종 소유 위치다. 현재 기능은 회귀 방지를 위해 기존 파일에서 그대로 실행되며 `LegacyManifest.lua`가 소유권과 의존성만 등록한다.

후속 모듈은 다음 계약을 따른다.

- `Module.lua`: 모듈 이름, 의존성, 공개 함수 등록
- `Service.lua`: 서버 명령·게임 동작
- `UI.lua`: 해당 기능의 프레임과 이벤트
- `Data.lua` 또는 `Generated/`: 기능 데이터
- `Locales/<locale>.lua`: 사용자 표시 문자열

모듈은 다른 모듈의 내부 함수나 프레임을 직접 덮어쓰지 않는다. 필요한 기능은 등록 함수 또는 공개 API를 통해 호출한다.
