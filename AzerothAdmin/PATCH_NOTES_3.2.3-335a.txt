AzerothAdmin 3.2.3-335a
Build date: 2026-08-18

Changes
1) Item quantity add fix
- Reworked the 3.3.5 StaticPopup edit-box lookup so both dialog.editBox and StaticPopupXEditBox are supported.
- OnAccept now falls back to dialog.data on 3.3.5 clients.
- Quantity is clamped to 1..9999 and the exact value is sent with:
  .additem <current GM player> <itemID> <count>
- Enter-key submit also resolves the 3.3.5 named popup button.
- InvenCraftInfo result/reagent buttons use the same quantity popup.

2) InvenCraftInfo full UI rebuild
- Removed the loaded legacy InvenCraftInfoUI multi-layer frame implementation.
- Added one single-frame UI: Embedded/InvenCraftInfoUI/Rebuilt.lua
- Visual language follows BlueItemInfo3: dark background, gold border/title, cyan hints.
- Left: profession list.
- Center: recipe/item list + search + paging.
- Right: output item + reagents.
- Result item left-click: quantity popup -> GM bag.
- Reagent left-click: quantity popup -> GM bag.
- Right-click on item/reagent: existing item context menu.
- Profession data falls back to the original InvenCraftInfo 1.8.1 SpellDB/SpellReqDB.
- For professions with original trade links, the rebuild loads a hidden linked 3.3.5 TradeSkill view, captures the complete recipe/reagent data, and immediately hides the Blizzard TradeSkillFrame.
- This preserves recipes that do not have a normal inventory output item (notably enchant-style profession entries) while keeping the custom UI as the only visible profession window.
