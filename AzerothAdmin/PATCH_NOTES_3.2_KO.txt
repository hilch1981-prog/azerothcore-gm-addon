AzerothAdmin 3.2.0-335a 패치 노트
================================

1. 은행 가방
- 원격 은행 창이 열린 동안 별도로 뜨는 작은 은행/빈 칸 팝업을 지속 감시하여 숨기도록 수정했습니다.
- 원격 은행 창은 화면 중앙 배치를 유지합니다.

2. InvenCraftInfo
- 아이템 정보창의 다크/골드 UI/UX를 참고해 InvenCraftInfo 자체를 하나의 900x600 통합 프레임으로 다시 배치했습니다.
- 기존 ClassTrainer 외곽 아트는 숨기고 제작 목록/선택 도안 상세을 같은 프레임 안에 정리했습니다.
- 외부/구버전 Inven Craft Info 창이 같이 뜨는 경우, 통합 창이 보이는 동안 지속적으로 숨깁니다.
- 전문기술을 변경할 때 이전 목록/재료/선택 정보가 남지 않도록 목록과 상세 상태를 즉시 초기화합니다.
- WoW 3.3.5a API만 사용하며 C_Container/C_Item/ScrollBox 계열 Retail API는 사용하지 않습니다.

3. 부활
- 사망/유령 상태에서는 선택 대상을 비운 뒤 .revive를 자기 자신에게 WHISPER 패킷으로 전송합니다.
- 0.35초 후에도 죽은 상태면 WHISPER 재시도, 0.90초 후에도 죽은 상태면 SAY 호환 재시도를 수행합니다.
- 생존 상태에서는 기존처럼 선택된 플레이어/자신에 대한 AzerothCore 기본 .revive 동작을 유지합니다.

4. 아이템 정보
- 전문기술 분류에 '낚시 도안/교본'을 추가했습니다.
- WotLK 3.3.5a 낚시 교본/공식/낚시 관련 도안 목록을 해당 분류에서 바로 확인할 수 있습니다.

5. 퀘스트 도우미
- 창 크기를 900x640으로 축소하고 한 페이지 퀘스트 수/목표 행 수를 재조정했습니다.
- 아이템/드랍 목표에 '드랍처 이동' 버튼을 추가했습니다.
- Questie/QuestieDB가 설치되어 있으면 item npcDrops/objectDrops를 읽어 실제 드랍 몬스터 또는 오브젝트 entry로 이동합니다.
- 드랍처가 여러 개면 버튼을 반복 클릭할 때 다음 원천으로 순환합니다.
- Questie 드랍 데이터가 없으면 기존 퀘스트 POI 이동으로 자동 대체합니다.

검증
- Lua 파일 41개 구문 검사 완료.
- TOC 참조 경로 검사 및 Retail 전용 API 미사용 검사 완료.
- 최종 ZIP 무결성 검사 완료 후 배포합니다.
