GM에드온[3.3.5a 아제로스코어] v3.0 변경사항

1. InvenCraftInfo 안정화
- 전문기술 전환 시 이전 전문기술 선택/재료가 남던 문제 수정.
- 재료 UI를 8행 단일 텍스트 목록으로 변경(아이콘 제거).
- 재료 클릭/도안 클릭을 막던 3.3.5a 비호환 IsModifiedClick() 무인수 호출 제거.
- 재료 클릭 -> 수량 팝업 -> .additem 캐릭터명 ItemID 수량.
- 도안/기술 -> .player learn 캐릭터명 SpellID [all].
- 습득 상태는 체크 아이콘 없이 초록(습득)/주황(미습득) 글자색으로 구분.

2. 아이템 정보 WotLK 정리
- 왼쪽 '분류' 목록을 처음부터 표시.
- 대격변 root(공격대/5인/세트/평판)와 관련 하위 분류 차단.
- WotLK 카테고리는 3.3.5a 범위 + 현재 WOW32 koKR ID 검증.
- 종류/등급 체크를 사전 선택 가능하게 하고 별도 '필터 적용' 버튼 추가.
- 체크할 때마다 전체 목록을 재로딩하지 않도록 변경.
- 아이템 클릭 -> 수량 팝업 -> 가방 추가 동작 복구.
- 수정키 아이템 링크 처리도 3.3.5a 방식으로 수정.

3. 은행/ESC 안정화
- 실제 BANKFRAME_OPENED 세션이 있을 때만 기본 BankFrame 사용.
- 원격에서는 .character check bank 서버 결과를 별도 이동 가능한 창에 표시.
- 가짜 BankFrame Show로 ESC가 잠기는 경로 제거.
- 원격 은행 서버 메시지 수집 시간을 5초로 확대.
- StaticPopup이 열려 있는 동안 Escape Proxy를 중지해 ESC가 팝업과 부모창을 동시에 닫지 않도록 수정.

4. 기타
- Interface 30300 유지.
- 퀘스트 도우미 ID/퀘스트명/레벨/지역 정렬 기능 유지.
