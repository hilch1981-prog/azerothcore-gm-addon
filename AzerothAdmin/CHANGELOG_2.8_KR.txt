GM에드온[3.3.5a 아제로스코어] v2.8

[GM 커맨드 재검증]
- 사용자 제공 acore_world.command 덤프(지엠커멘드.sql) 740개 명령을 메타데이터로 반영.
- 애드온의 명령 버튼 188개를 대조하여 등록 명령명 기준 미매칭 0개 확인.
- 각 명령 버튼에 command.security 기반 필요 GM 레벨과 공식 Syntax를 자동 연결.
- 인수 팝업에 공식 Syntax + 사용 예시를 함께 표시.
- 캐릭터 계정 이동 인수 순서 수정: 새계정명 캐릭터명.
- 일반 GUID는 플레이어 전용으로 수정, 크리쳐 GUID는 .npc guid 사용.
- .distance는 크리쳐 선택 기준으로 수정.
- .save/.dismount 설명을 자기 캐릭터 기준으로 수정.
- .recall/.cooldown/.combatstop의 불필요한 대상 강제 제한 완화.
- .character check bank는 인수 없는 자기 은행 검사 명령으로 수정.
- .character check profession은 선택 플레이어 기반으로 수정.
- deprecated .list object 버튼을 .gobject near 50 기반 스폰 목록으로 교체.
- .modify phase 대상 타입을 플레이어로 제한.

[실행 결과 표시]
- GM 명령 버튼 오른쪽에 ... / OK / 실패 / 잠금 상태 표시.
- CHAT_MSG_SYSTEM 서버 응답을 수집해 성공/실패를 판정.
- 실패 메시지는 버튼 툴팁의 최근 결과에도 표시.

[권한/RBAC 보조]
- 로그인 후 .account 응답으로 GM 보안 레벨 자동 감지 시도.
- command.security보다 현재 레벨이 낮으면 버튼 자동 잠금.
- security=4(Console) 명령은 게임 UI에서 자동 잠금.
- 실제 서버가 Permission/RBAC 오류를 반환한 명령은 해당 세션에서 즉시 잠금.
- GM 탭에 'GM 권한 재검사' 버튼 추가.
- /aa auth 명령 추가.

[GM 명령 퀵슬롯]
- 메인 명령 버튼 우클릭으로 즐겨찾기 등록/해제.
- 하단 미니바 오른쪽에 최대 4개의 명령 퀵슬롯 추가.
- 저장된 퀵슬롯은 SavedVariables에 유지.
- 권한 부족 명령은 퀵슬롯에서도 자동 비활성화.

[검색 우클릭 메뉴]
- 아이템: 수량 입력 후 가방 추가 / 보유 목록 조회 / 통합 아이템 정보.
- 퀘스트: 퀘스트 추가 / 시작 위치 / 종료 위치 / 퀘스트 도우미.
- 크리쳐: Entry 위치 이동 / 스폰 목록 / 현재 위치에 생성(확인창).
- 퀘스트 도우미 내부 검색 결과에도 동일한 우클릭 퀘스트 메뉴 적용.
[추가 안정화]
- GM 날기/무적/투명/속도/수면걷기 같은 Toggle 액션도 실제 command.security와 연결해 메인 버튼을 사전 잠금.
- 미니바 및 검색 우클릭에서 직접 실행한 명령도 Permission/RBAC 거부 응답을 감지하면 해당 세션에서 잠금.
- 검색 우클릭 메뉴 자체도 현재 감지된 GM 레벨보다 높은 서버 명령은 비활성화.
- .character check bag 공식 구문을 [캐릭터명] 가방슬롯(1~4)로 보정.
- .revive는 공식 구문대로 대상이 없으면 자신에게 적용되도록 불필요한 플레이어 선택 강제를 제거.
- Permission/RBAC 오류뿐 아니라 unknown/no such command 응답도 세션 중 자동 잠금 처리.
