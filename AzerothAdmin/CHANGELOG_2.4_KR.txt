GM에드온[3.3.5a 아제로스코어] v2.4

- 미니바 무적 모드(God) 버튼 추가
- 은행 버튼: v2.5에서 기본 BankFrame 중앙 토글 방식으로 교체됨
- 검색 탭을 3종으로 단순화
  · 아이템 한글/ID 검색
  · 퀘스트 한글/ID 검색
  · 크리쳐 한글/ID 검색
- 아이템 검색 결과 클릭 시 수량 입력 팝업 → .additem으로 즉시 가방 생성
- 검색 창 종류를 바꿀 때 이전 검색어/결과 자동 초기화
- 즐겨찾기 '상인섬'을 AzerothCore GMIsland로 명칭/좌표 정리
- ESC로 메인/검색/텔레포트/즐겨찾기/퀘스트/인수 창 닫기
- 메인 GM메뉴 첫 페이지에 퀘스트 도우미 배치
- 퀘스트 도우미 열:
  완료 / 시작위치 / 종료위치 / 목표 보기
- 3.3.5a GetQuestLogItemDrop 기반 추가 드롭 목표를 목표 표에 자동 병합
- koKR 아이템/크리쳐 이름에서 목표 ID 자동 해석
- 몹 목표는 creature ID가 확인되면 .go creature id 사용
- 서버 Quest POI가 제공되면 .go zonexy로 목표/드롭 위치 이동 시도
- 창 중첩 방지: 새 창을 열면 기존 GM 애드온 창 자동 닫기
