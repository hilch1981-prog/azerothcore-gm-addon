GM에드온[3.3.5a 아제로스코어] v2.9 변경사항
============================================================

1. InvenCraftInfo GM 연동 보강
- 재료 버튼이 선택 레시피의 ItemID를 직접 저장하도록 수정.
- ItemLink가 없을 때 koKR 아이템명 인덱스로 ItemID를 보조 확인.
- 재료 좌클릭 -> 수량 입력 -> 현재 GM 캐릭터 가방에 .additem 처리.
- 기존 코드의 reagentName 오타(regentName)를 수정하여 재료명/검색 안정성 향상.
- 미습득 도안/기술에 + 버튼 표시, 습득 완료 항목은 체크 표시.
- 도안 행 클릭 및 상세창 'GM 습득' 버튼에서 .player learn 사용.
- 도안 SpellID를 RecipeLink뿐 아니라 제작 아이템→SpellDB 역조회로도 보완.
- 전문기술 탭에서 미습득 기술 클릭 시 전체 랭크 습득 확인창 표시.
- 도안 목록에 기존 난이도 색상을 유지하고 [숙련 / Lv. / iLv.] 정보를 추가.
- 재료명은 아이템 등급 색상을 사용하며 [Lv. / iLv.] 정보를 표시.

2. Blue Item Info 3 통합 브라우저 확장
- 별도 '아이템 한글/ID 검색' 버튼 삭제. 아이템 정보 창 안에 검색을 통합.
- 원본 Blue Item Info ItemDB의 분류 데이터를 추가 인덱싱.
- 23개 대분류 / 1,613개 세부분류 / 19,905개 분류 링크 구성.
- 보석 / 전문 기술 / 아이템 강화 / 세트 / 평판 / PvP / 화폐 / 퀘스트 보상 등 분류 복구.
- 아이템 등급별 색상과 Lv./iLv. 표시.
- 도안/주문형 음수 ID도 목록에서 표시하고 우클릭 시 GM 습득 가능.
- koKR 한글명/ID 검색, 획득처 툴팁, 우클릭 GM 메뉴 유지.

3. 은행 가방 창
- 과거 정상 동작하던 BankFrame:Show() 방식을 우선 사용하도록 복구.
- ShowUIPanel은 보조 fallback으로만 사용.
- 중앙 기본 위치 / 드래그 이동 / 위치 저장 / 같은 버튼으로 열기·닫기 유지.

4. 창/ESC 계층 동작
- 메인창 -> 세부창 -> 하위창 순으로 열린 상태를 추적.
- ESC 또는 닫기 버튼은 가장 마지막에 연 창부터 닫음.
- 자식창을 닫으면 직전 부모창을 자동 복원.
- 퀘스트 검색 결과 같은 내부 하위창도 먼저 닫도록 처리.

5. 인수값 입력창
- 공식 command Syntax를 기준으로 인수명을 자동 설명.
- 계정명/캐릭터명/ItemID/SpellID/QuestID/GUID/좌표/RealmID 등 설명 표시.
- on/off, GM 레벨 0~3, RealmID -1, 확장팩 단계 등 주요 선택값 의미 추가.
- 실제 명령 미리보기 / 공식 Syntax / 실행 예시 동시 표시.

6. 퀘스트 도우미
- 진행 목록 컬럼을 ID / 퀘스트명 / 레벨 / 지역으로 분리.
- 각 컬럼 제목 클릭 시 오름차순/내림차순 정렬.
- 현재 캐릭터 대비 퀘스트 난이도 색상 유지.
- 완료 / 시작위치 / 종료위치 / 목표 기능 유지.
- 목표 아이템 조회는 통합 Blue Item Info 검색창으로 연결.

7. 검증
- 사용자 지엠커멘드.sql command 740개와 애드온 command 필드 188개 재대조: 미매칭 0.
- Interface 30300 확인.
- TOC 참조 41개 / 누락 0.
- Lua 파일 41개 정적 구문 검사 통과(WoW Lua 5.1의 .goto 필드는 테스트 사본에서만 정규화).
