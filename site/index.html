PROJECT GOAL

가짜 기능보다 실제 서버 동작을 우선합니다.

Retail 전용 API를 사용하지 않고, WotLK 3.3.5a와 AzerothCore의 실제 명령 및 이벤트 흐름을 기준으로 구현합니다. 게임 내 검증이 끝나지 않은 항목은 사이트에서도 완료로 표시하지 않습니다.

CORE FEATURES

GM 운영에 자주 필요한 기능을 한 곳에

현재 저장소에 실제 구현 위치가 확인된 기능만 소개합니다.

01

퀘스트 도우미

진행 상태, 목표 상세, 선택 하이라이트, Questie 기반 아이템 드랍처 이동과 반복 순환을 지원합니다.

02

아이템 정보

WotLK 퀘스트 보상, 전문기술·강화 분류, 아이템 추가 기능을 독립 프레임에서 제공합니다.

03

전문기술 정보

InvenCraftInfo를 아이템 정보와 분리 유지하며, 검색·정렬·상세·재료 상태를 관리합니다.

04

주요 크리처 브라우저

주요 크리처 187개 분류, 스크롤 목록, 위치 이동, 스폰 정보, 소환과 3D 외형 미리보기를 제공합니다.

05

원격 은행 & 자기 부활

AzerothCore 실제 서버 처리 경로를 사용해 원격 은행 세션과 사망·유령 상태 자기 부활을 처리합니다.

06

GM 명령 & 퀵슬롯

명령 메타데이터를 감사하고, 자주 쓰는 GM 명령과 애드온 기능을 퀵슬롯에 저장해 빠르게 실행합니다.

DESIGN PRINCIPLE

기존 애드온의 다크 + 골드 UI 흐름을 유지

3.3.5a 기본 Frame, ScrollFrame, FrameStrata, FrameLevel을 중심으로 구성하며 아이템 정보와 InvenCraftInfo처럼 역할이 다른 창은 시각적 통일감만 맞추고 로직은 분리합니다.

  • 기존 파일·기능·SavedVariables 최대한 보존
  • Retail 전용 API 사용 금지
  • 사용자에게 의미 없는 중간 팝업 제거
  • 팝업과 선택 상태의 레이어·수명주기 회귀 검사

INSTALL

AddOns 폴더에 복사

3

게임에서 실행

접속 후 채팅창에 /aa를 입력해 메인 GM 창을 엽니다.

중요

GitHub Actions 또는 Lua/TOC 정적 검사가 성공해도 게임에서 실제 기능이 모두 정상이라는 뜻은 아닙니다. 프로젝트 규칙에 따라 게임 내 검증 전에는 완료로 간주하지 않습니다.
